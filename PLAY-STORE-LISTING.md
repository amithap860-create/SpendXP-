## Step-by-Step Submission Checklist

### Before submitting:
- [ ] `git push origin main` — code is live on Vercel
- [ ] Add Razorpay env vars to Vercel and redeploy
- [ ] `firebase deploy --only firestore:rules`
- [ ] Test the live app at https://spendxp.vercel.app — sign up, play a game, upgrade
- [ ] Android Studio build (see GOOGLE-PLAY-PUBLISH-GUIDE.md)

### In Play Console:
- [ ] Create developer account at https://play.google.com/console (your dad's Google account, $25 one-time fee)
- [ ] "Create app" → enter app name, language, free
- [ ] Fill in Store listing using content above
- [ ] Upload screenshots (6 phone screenshots + feature graphic)
- [ ] Upload AAB file from Android Studio
- [ ] Fill in content rating questionnaire
- [ ] Set up pricing (free + in-app purchases)
- [ ] Internal testing → Production → Submit for review
- [ ] Google review takes 3–7 days

### Timeline to August 2026:
- You have ~5 weeks — plenty of time if you start the developer account this week
