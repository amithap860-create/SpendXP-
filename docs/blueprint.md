# **App Name**: SpendXP

## Core Features:

- Personalized Learning Portal: User registration and login, with content adapting to age groups (8-11, 11-15, 16-20) and persistent session memory.
- Interactive Flashcards: Educational flashcards covering financial terms and concepts, with content difficulty automatically adjusted to the user's age level using an AI tool.
- Virtual Market Simulation: Kids can 'invest' virtual money in fictional companies, observing price changes and tracking their portfolio's performance over time.
- AI-Driven Market Insights: An AI tool dynamically generates simplified news events impacting virtual stock prices and provides educational pop-ups explaining concepts like volatility and investment strategies.
- Gamified Savings Tracker: Users can set and track virtual savings goals through an engaging, game-like interface to foster positive financial habits.
- Progress Dashboard: A central dashboard displaying the student's learning achievements, virtual investment performance, and savings progress.

## Style Guidelines:

- Primary color: A confident and trustworthy deep blue (#2E72DB) to inspire learning and stability.
- Background color: A very subtle, airy light blue (#EEF3FF) to provide a clean and calm canvas, preventing eye strain for young users.
- Accent color: A vibrant, clear sky blue (#19C0ED) to highlight interactive elements, calls to action, and draw attention to important information.
- Body and headline font: 'Inter' (sans-serif) for its modern, clean, and highly readable design, ensuring clarity for all age groups.
- Utilize high-quality, simple, static vector graphics and icons for intuitive navigation and visual understanding, appropriate for a diverse age range.
- Clear and spacious layouts with intuitive navigation paths to make complex financial topics easily digestible and accessible for young learners.
